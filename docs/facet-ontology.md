# Facet Ontology

## Core Principles

1. **Everything is a facet** - All state, events, and changes are represented as facets
2. **Facets have aspects** - Composable interfaces that define capabilities
3. **Endotemporal vs Exotemporal**:
   - **Endotemporal**: Changes within the simulated world (facets)
   - **Exotemporal**: Changes to the VEIL itself (deltas: add/change/remove)

## Aspect Interfaces

```typescript
// Has human/agent-readable content
interface ContentAspect {
  content: string;
}

// Has structured state data (for programmatic use)
interface StateAspect<T = Record<string, any>> {
  state: T;
}

// Generated by an agent (not external events)
interface AgentGeneratedAspect {
  agentId: string;
  agentName?: string;
}

// Removed at end of frame
interface EphemeralAspect {
  ephemeral: true;
}

// Belongs to specific scopes
interface ScopedAspect {
  scopes: string[];
}

// References other facets
interface TargetedAspect {
  targetFacetIds: string[];
}

// Belongs to a specific stream
interface StreamAspect {
  streamId: string;
  streamType?: string;
}

// Base for all facets
interface BaseFacet {
  id: string;
  type: string;
}
```

## Facet Types

### 1. Agent Communication Facets

```typescript
// What agents say
type SpeechFacet = BaseFacet & ContentAspect & AgentGeneratedAspect & StreamAspect & {
  type: 'speech';
};

// Agent's internal reasoning 
type ThoughtFacet = BaseFacet & ContentAspect & AgentGeneratedAspect & StreamAspect & {
  type: 'thought';
};

// Actions/tool use
type ActionFacet = BaseFacet & ContentAspect & StateAspect<{
  toolName: string;
  parameters: Record<string, any>;
}> & AgentGeneratedAspect & StreamAspect & {
  type: 'action';
};
```

### 2. Core Content Facets

These are the four fundamental facets that carry content visible to agents:

```typescript
// Events - things that happen at a specific moment
type EventFacet = BaseFacet & ContentAspect & StateAspect<{
  source: string;      // Hierarchical source identifier
  eventType: string;   // What kind of event
  metadata?: any;
}> & StreamAspect & {
  type: 'event';
};

/**
 * Source is for traceability - where the event content came from.
 * Examples: "discord:channel:general", "console", "timer:daily-backup"
 * 
 * This is NOT for turn attribution. Turn attribution is determined by
 * what triggered the frame creation at the Space level.
 */

// State - the current state of things in the world
type StateFacet = BaseFacet & ContentAspect & StateAspect & ScopedAspect & {
  type: 'state';
  entityType: 'component' | 'element' | 'agent';
  entityId: string;
};

// Ambient - background information, atmosphere, context
type AmbientFacet = BaseFacet & ContentAspect & StreamAspect & {
  type: 'ambient';
};

// Ephemeral - temporary information that doesn't persist
type EphemeralFacet = BaseFacet & ContentAspect & EphemeralAspect & {
  type: 'ephemeral';
};
```

### 3. Configuration Facets

```typescript
// Configuration (not visible to agents)
type ConfigFacet = BaseFacet & StateAspect & {
  type: 'config';
  configType: string;
};

// Internal component state (not visible to agents)
type InternalStateFacet = BaseFacet & StateAspect & {
  type: 'internal-state';
  componentId: string;
};
```

### 4. Meta-Facets (Endotemporal Changes)

```typescript
// Records that state changed
type StateChangeFacet = BaseFacet & TargetedAspect & StateAspect<{
  changes: Record<string, { old: any; new: any }>;
}> & EphemeralAspect & {
  type: 'state-change';
};

// Scope management
type ScopeChangeFacet = BaseFacet & StateAspect<{
  operation: 'add' | 'remove';
  scopeId: string;
  scopeData?: any;
}> & EphemeralAspect & {
  type: 'scope-change';
};

// Stream management
type StreamChangeFacet = BaseFacet & StateAspect<{
  operation: 'add' | 'remove' | 'activate';
  streamId: string;
  streamType?: string;
}> & EphemeralAspect & {
  type: 'stream-change';
};

// Agent lifecycle
type AgentLifecycleFacet = BaseFacet & StateAspect<{
  operation: 'register' | 'deregister' | 'activate' | 'deactivate';
  agentId: string;
  agentInfo?: any;
}> & EphemeralAspect & {
  type: 'agent-lifecycle';
};
```

### 5. System Facets

```typescript
// Triggers agent processing
type AgentActivationFacet = BaseFacet & StateAspect<{
  reason: string;
  priority: 'low' | 'normal' | 'high' | 'critical';
  sourceAgentId?: string;
}> & EphemeralAspect & {
  type: 'agent-activation';
};

// Rendered context for agents
type RenderedContextFacet = BaseFacet & ContentAspect & StateAspect<{
  activationId: string;
  tokenCount: number;
  compressionRatio?: number;
}> & EphemeralAspect & {
  type: 'rendered-context';
};

// Action definitions (tools available to agents)
type ActionDefinitionFacet = BaseFacet & StateAspect<{
  actionName: string;
  parameters: string[];
  description: string;
  handler: string;
}> & {
  type: 'action-definition';
};
```

## Usage Patterns

### Receptors
- Consume external events (SpaceEvents)
- Emit facets including meta-facets (state changes, scope changes, etc.)
- Often create EventFacets to record external inputs

### Transforms  
- See all facets (including meta-facets from receptors)
- Can emit additional facets based on current state
- Example: `StateChangeFacet` triggers derived state updates

### Effectors
- React to facet deltas (exotemporal changes)
- Emit external events
- Perform side effects

## Migration Notes

1. **Operations → Deltas**: `VEILOperation` becomes `VEILDelta` with only add/change/remove
2. **State tracking**: Components emit `StateChangeFacet` instead of direct mutations
3. **Scopes as facets**: Scope additions/removals are now traceable events
4. **Agent activation**: No more special events - just `AgentActivationFacet`
5. **Errors**: No dedicated ErrorFacet - errors are EventFacets or EphemeralFacets with error data

## Benefits

1. **Uniform model**: Everything follows the same pattern
2. **Traceable**: All changes are recorded as facets
3. **Composable**: Aspects make it clear what capabilities each facet has
4. **Type-safe**: TypeScript ensures correct aspect usage
5. **Temporal clarity**: Clear distinction between endo/exotemporal changes
